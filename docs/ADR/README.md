## Convenções

- Numerar novas decisões sequencialmente.
- Não apagar ADRs aceitas, rejeitadas ou substituídas.
- Registrar status e data da decisão.
- Referenciar documentos de Sprint e componentes reais afetados.
- Não tratar ADR como prova de deploy, migration ou estado de ambiente.

# Dominio Usuarios

Estrutura reservada para a futura migracao do dominio de usuarios.

## Objetivo futuro

Centralizar identidade interna, perfis, papeis, vinculos e permissao de usuarios.

## Estrutura

- `controllers/`: futuros controllers do dominio.
- `services/`: futuros services do dominio.
- `repositories/`: futuros repositories do dominio.
- `validators/`: futuros validadores do dominio.
- `types/`: futuros tipos e contratos do dominio.

## Estado atual

Nenhum modulo existente foi migrado nesta Sprint. Autenticacao e usuarios atuais permanecem intactos.

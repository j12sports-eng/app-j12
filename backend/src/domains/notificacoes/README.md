# Dominio Notificacoes

Estrutura reservada para a futura migracao do dominio de notificacoes.

## Objetivo futuro

Centralizar criacao, leitura, marcacao, escopo e eventos de notificacoes.

## Estrutura

- `controllers/`: futuros controllers do dominio.
- `services/`: futuros services do dominio.
- `repositories/`: futuros repositories do dominio.
- `validators/`: futuros validadores do dominio.
- `types/`: futuros tipos e contratos do dominio.

## Estado atual

Nenhum modulo existente foi migrado nesta Sprint. A extracao anterior de repository permanece fora desta estrutura de dominio.

# Dominio Dashboard

Estrutura reservada para a futura migracao do dominio de dashboard.

## Objetivo futuro

Centralizar agregadores, indicadores, widgets e contratos de leitura do dashboard.

## Estrutura

- `controllers/`: futuros controllers do dominio.
- `services/`: futuros services do dominio.
- `repositories/`: futuros repositories do dominio.
- `validators/`: futuros validadores do dominio.
- `types/`: futuros tipos e contratos do dominio.

## Estado atual

Nenhum modulo de dashboard existente foi migrado nesta Sprint. Rotas e widgets atuais permanecem intactos.

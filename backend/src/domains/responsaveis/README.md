# Dominio Responsaveis

Estrutura reservada para a futura migracao do dominio de responsaveis.

## Objetivo futuro

Centralizar vinculos entre responsaveis, alunos, portais e notificacoes.

## Estrutura

- `controllers/`: futuros controllers do dominio.
- `services/`: futuros services do dominio.
- `repositories/`: futuros repositories do dominio.
- `validators/`: futuros validadores do dominio.
- `types/`: futuros tipos e contratos do dominio.

## Estado atual

Nenhum modulo existente foi migrado nesta Sprint. O fluxo atual de responsaveis permanece nos arquivos legados.

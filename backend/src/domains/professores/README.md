# Dominio Professores

Estrutura reservada para a futura migracao do dominio de professores.

## Objetivo futuro

Centralizar regras de cadastro, vinculos, turmas, presencas e contratos relacionados a professores.

## Estrutura

- `controllers/`: futuros controllers do dominio.
- `services/`: futuros services do dominio.
- `repositories/`: futuros repositories do dominio.
- `validators/`: futuros validadores do dominio.
- `types/`: futuros tipos e contratos do dominio.

## Estado atual

Nenhum modulo existente foi migrado nesta Sprint. O fluxo atual de professores permanece nos arquivos legados.

# Dominio Alunos

Estrutura reservada para a futura migracao do dominio de alunos.

## Objetivo futuro

Centralizar casos de uso, validacoes, acesso a dados e tipos relacionados a alunos.

## Estrutura

- `controllers/`: futuros controllers do dominio.
- `services/`: futuros services do dominio.
- `repositories/`: futuros repositories do dominio.
- `validators/`: futuros validadores do dominio.
- `types/`: futuros tipos e contratos do dominio.

## Estado atual

Nenhum modulo existente foi migrado nesta Sprint. O fluxo atual de alunos permanece nos arquivos legados.

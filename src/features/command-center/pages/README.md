# Pages

## Finalidade

Compor visualmente o Centro de Comando sem conhecer a origem dos dados.

## Responsabilidades

- Organizar cabeçalho, toolbar, filtros, KPIs, seções e widgets.
- Reutilizar a biblioteca visual criada nas Sprints anteriores.
- Receber todo conteúdo, métricas e callbacks por propriedades.

## Dependências

Componentes visuais e configurações da própria feature.

## Regras de uso

Uma page não pode importar APIs, hooks BI, stores, rotas, serviços ou contratos
de banco. A preparação dos dados pertence ao container.
